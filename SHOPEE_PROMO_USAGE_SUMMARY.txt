步骤 1️⃣  安装依赖 (仅需一次)
────────────────────────────────────────────────────────────────────────────
在您的计算机上运行：

  pip install Pillow

  python /path/to/memetalk/shopee_promo_image_script.py

────────────────────────────────────────────────────────────────────────────
在脚本目录中查找生成的图片：

  shopee_promo.png  (1080 × 1920 像素)

    /images/product.jpeg \
    /images/backend.png \

🎯 常见使用场景
═══════════════════════════════════════════════════════════════════════════════

场景 1: 生成默认海报
  $ python shopee_promo_image_script.py
  ✅ 输出: shopee_promo.png


场景 2: 每次生成不同的输出文件名
  $ python shopee_promo_image_script.py \
      input_file_12.jpeg \
      input_file_16.jpeg \
      promo_v1.png
  $ python shopee_promo_image_script.py \
      input_file_12.jpeg \
      input_file_16.jpeg \
      promo_v2.png


场景 3: 使用不同的商品图片和後台截圖
  $ python shopee_promo_image_script.py \
      product_set_a.jpg \
      backend_screenshot_a.png \
      promo_set_a.png


场景 4: 批量生成（需要编写 shell 脚本或 Python 循环）
  for file in products/*.jpg; do
    python shopee_promo_image_script.py "$file" backend.png "output_${file%.jpg}.png"
  done

🔧 故障排除
═══════════════════════════════════════════════════════════════════════════════

问题 1: "ModuleNotFoundError: No module named 'PIL'"
解决: pip install Pillow

问题 2: "FileNotFoundError: [Errno 2] No such file or directory"
解决: 检查输入文件路径是否正确
     $ ls -l input_file_*.jpeg

问题 3: 文字显示为方块或乱码
解决: 安装中文字体
     Ubuntu/Debian: sudo apt-get install fonts-noto-cjk
     macOS: 系统已预装 PingFang 字体
     Windows: 系统已预装微软雅黑

问题 4: "OSError: cannot identify image file"
解决: 输入文件损坏或格式不支持，尝试用其他图片编辑器打开验证

💡 提示和建议
═══════════════════════════════════════════════════════════════════════════════

💡 提示 1: 输入图片质量
   建议使用分辨率 >= 1000px 的高质量原始图片，生成效果会更好

💡 提示 2: 自动调整大小
   脚本会根据输入图片的宽高比自动调整缩放，无需手动剪裁

💡 提示 3: 输出格式
   生成的 PNG 文件支持透明度，可直接用于设计软件进一步编辑

💡 提示 4: 社交媒体优化
   输出的 1080×1920 尺寸适合：
   • Instagram Stories (1080×1920)
   • TikTok 竖版 (1080×1920)
   • 微博竖版视频 (1080×1920)
   • Pinterest (1000×1500 需缩放)

💡 提示 5: 批量生成
   需要生成多个版本时，可编写简单的 Python 或 Shell 脚本循环调用
